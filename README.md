# OtoAI Rehberi

## Proje hakkında

**OtoAI Rehberi**, yapay zeka ve otomasyon araçlarını anlaşılır biçimde tanıtan
basit ve erişilebilir bir web sitesidir. Projenin hedef kitlesi, bu araçları
öğrenmeye başlayan üniversite öğrencileri ve geliştiricilerdir.

## Proje dosya yapısı

```text
OtoAI-Rehberi/
├── index.html       # Ana sayfa
├── icerikler.html   # Araç rehberleri ve arama alanı
├── hakkinda.html    # Proje hakkında bilgileri
├── style.css        # Üç sayfada ortak koyu tema ve responsive düzen
├── script.js        # İçerik arama, sayaç ve Temizle işlevleri
├── README.md
├── AI_NOTLARI.md
└── TEST_NOTLARI.md
```

## Yerel bilgisayarda çalıştırma

1. Depoyu bilgisayara indirin veya klonlayın:

   ```bash
   git clone https://github.com/abdestar/OtoAI-Rehberi.git
   ```

2. Proje klasörünü açın.
3. `index.html` dosyasını bir web tarayıcısında açın.
4. Menüden **İçerikler** sayfasına geçerek başlığa göre anlık aramayı
   deneyebilirsiniz. Proje için ayrıca bir sunucu veya paket kurulumu
   gerekmemektedir.
